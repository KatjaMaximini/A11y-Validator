# A11y-Validator (Study Project)
Design of an Accessibility Validator as part of the assignment (ESA) of the Software Engineering module (THB MIB 20 S26)
It focuses on the requirements engineering and conceptual design of an accessibility validation tool for HTML documents.

## 🎯 Project Goal
The A11y-Validator is designed to help web developers identify accessibility issues (based on WCAG 2.1) early in the development process. 
The goal is to ensure that web content is perceivable, operable, and understandable for all users.

## 🛠 Features (MVP Scope)
- **HTML Upload:** Upload or paste HTML snippets for analysis.
- **Automated Checks:** Identification of missing `alt`-attributes, incorrect heading hierarchies, and contrast issues.
- **Actionable Reports:** Detailed error reporting with line numbers and suggestions for improvement.

## 📏 Quality Standards
Following **ISO/IEC 25010**, this project prioritizes:
- **Portability:** Browser-based accessibility.
- **Usability:** Simple, intuitive interface for developers.
- **Maintainability:** Modular architecture to easily add new WCAG rules.

## 🚀 Project Management
Requirements are managed using the **MoSCoW method** and organized within this GitHub repository:
- **Must-haves (A-Tasks):** Core validation engine and basic UI.
- **Should-haves (B-Tasks):** JSON export and advanced reporting.

The progress is tracked via [GitHub Projects](https://github.com/users/KatjaMaximini/projects/1/views/1) and [Issues](https://github.com/KatjaMaximini/A11y-Validator/issues).
